Kroniki Matematyki 4 epoki

Starożytność (3000 p.n.e. – 500 n.e.)
Matematyka powstała z potrzeby — Egipcjanie mierzyli Nil i budowali piramidy, Babilończycy stworzyli system sześćdziesiątkowy (nadal używamy go w minutach i stopniach). Przełom: Grecy (Pitagoras, Euklides, Archimedes) wprowadzili dowód matematyczny — wiedza przestała być empiryczna, a stała się absolutną prawdą.
Twierdzenie Pitagorasa (ok. 570 p.n.e.): a² + b² = c² — dowiedzione przez Euklidesa na 46 różnych sposobów.
Złoty Wiek Islamu & Indie (500–1400)
Indie podarowały światu zero jako pełnoprawną liczbę i system pozycyjny dziesiętny. Al-Chuwarizmi (skąd pochodzi słowo "algorytm") napisał "Kitāb al-mukhtaṣar fī ḥisāb al-jabr" — pierwsze systematyczne omówienie algebry. Bez tego tłumaczenia na łacinę Europa nie miałaby podstaw do Rewolucji Naukowej.
Al-jabr → Algebra. Al-Chuwarizmi → Algorithm. Cyfra arabska 0 → cały system pozycyjny.
Rewolucja Naukowa (1500–1800)
Newton i Leibniz niezależnie wynaleźli rachunek różniczkowy i całkowy (największy spór w historii nauki). Pozwoliło to obliczać prędkości chwilowe, modelować ruch planet i zaprojektować silniki parowe. Euler sformalizował notację: \(e, \pi, i, f(x), \sum, \Delta\) — używamy jej do dziś. Wielki Twierdzenie Fermata (1637) czekało na dowód 358 lat.
e^(iπ) + 1 = 0 — tożsamość Eulera: 5 najważniejszych stałych matematyki w jednym równaniu.
Era Komputerów (1900–teraz)
Hilbert sformułował 23 wielkie problemy (1900) — część nierozwiązana do dziś. Gödel udowodnił (1931), że każdy spójny system aksjomatyczny zawiera twierdzenia nierozstrzygalne. Turing stworzył matematyczne podstawy komputerów. Dziś kryptografia RSA, uczenie maszynowe i grafika 3D opierają się wprost na teorii grup, algebrze liniowej i rachunku różniczkowym.
Problem P vs NP — jeden z 7 Problemów Milenijnych. Nagroda: 1 000 000 USD. Nierozwiązany.

Anomalie Wszechświata 6 faktów

0.999... = 1 (dokładnie)
Nie przybliżenie — fakt analityczny. Dowód: \(\frac{1}{3} = 0.333...\), więc \(3 \times \frac{1}{3} = 0.999...\), ale \(\frac{3}{3} = 1\). Formalnie: \(0.\overline{9} = \sum_{n=1}^{\infty} \frac{9}{10^n} = 1\). Sprzeciw intuicji wynika z błędnego wyobrażenia o nieskończoności, nie z błędu matematyki.
Hotel Hilberta
Hotel z nieskończenie wieloma pokojami, wszystkie zajęte. Przyjeżdża nowy gość — czy może go przyjąć? Tak: przenosimy gościa z pokoju n do pokoju n+1. Pokój 1 wolny. Dowód: ∞ + 1 = ∞. To nie paradoks — to definicja nieskończoności kardynalnej według Cantora.
Liczba Googolplex
Googol = \(10^{100}\). Googolplex = \(10^{10^{100}}\). Jest tak ogromna, że jej zapis dziesiętny nie zmieściłby się w obserwowalnym wszechświecie. Liczba atomów w wszechświecie: ~\(10^{80}\). Googol jest miliardy razy miliardy razy większy od tej liczby.
Złota Proporcja φ
Ciąg Fibonacciego: 1, 1, 2, 3, 5, 8, 13... Iloraz kolejnych wyrazów: \(\frac{F_{n+1}}{F_n} \to \varphi = \frac{1+\sqrt{5}}{2} \approx 1{,}618\). Pojawia się w spirali ślimaka, układzie nasion słonecznika, proporcjach DNA i partyturach muzycznych Debussy'ego.
Teoria Chaosu
Układ deterministyczny (dokładne prawa fizyki, zero losowości) może być nieprzewidywalny. Nieznaczna zmiana warunków początkowych prowadzi do radykalnie innych wyników. Efekt motyla Lorenza (1963): \(\dot{x} = \sigma(y-x)\), \(\dot{y} = x(\rho-z)-y\), \(\dot{z} = xy-\beta z\) — trzy proste równania, nieskończona złożoność.
Paradoks Urodzin
W grupie zaledwie 23 osób prawdopodobieństwo, że dwie z nich mają urodziny tego samego dnia, przekracza 50%. Przy 70 osobach — 99.9%. Obliczenie: \(P(\text{brak}) = \frac{365}{365} \cdot \frac{364}{365} \cdot \frac{363}{365} \cdots\). Kontr-intuicyjne, ale matematycznie precyzyjne.

Baza Wiedzy

Fundamentalne Stałe

Liczby niewymierne i przestępne — ich rozwinięcie dziesiętne jest nieskończone i nieokresowe. Fundamentalne dla analizy, geometrii i fizyki.
π ≈ 3.14159265358979... — stosunek obwodu koła do średnicy e ≈ 2.71828182845904... — podstawa logarytmu naturalnego
φ = (1+√5)/2 ≈ 1.61803398... — złota proporcja i = √(-1) — jednostka urojona, baza liczb zespolonych
Tożsamość Eulera: e^(iπ) + 1 = 0 — łączy wszystkie 5 stałych w jednym równaniu.

Algebra

Wzory Skróconego Mnożenia
$$(a \pm b)^2 = a^2 \pm 2ab + b^2$$ $$a^2 - b^2 = (a-b)(a+b)$$ $$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$$ $$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$$
Przykład: (2x+3)² = 4x² + 12x + 9  |  x⁴−16 = (x²−4)(x²+4) = (x−2)(x+2)(x²+4)
Najczęstszy błąd: pominięcie środkowego wyrazu 2ab w kwadracie sumy.
Potęgi i Pierwiastki
$$a^m \cdot a^n = a^{m+n} \qquad \frac{a^m}{a^n} = a^{m-n}$$ $$(a^m)^n = a^{m\cdot n} \qquad (ab)^n = a^n b^n$$ $$a^0 = 1 \quad a^{-n} = \frac{1}{a^n} \quad a^{\frac{m}{n}} = \sqrt[n]{a^m}$$
2³ · 2⁵ = 2⁸ = 256  |  27^(2/3) = (∛27)² = 3² = 9
Równania Liniowe i Nierówności
Schemat: przenieś x na lewą stronę, liczby na prawą, podziel przez współczynnik. Przy mnożeniu/dzieleniu przez liczbę ujemną — odwróć znak nierówności.
$$ax + b = c \Rightarrow x = \frac{c-b}{a}$$
5x - 3 > 2x + 9 → 3x > 12 → x > 4. Zbiór: (4, +∞)
Mnożysz obie strony przez −2? Odwróć > na <!

Funkcja Kwadratowa

Funkcja \(f(x) = ax^2 + bx + c\) opisuje parabolę — trajektorię rzutu ukośnego, kształt luster teleskopów i soczewek optycznych. Trzy formy zapisu są równoważne.
Postać ogólna
$$y = ax^2 + bx + c$$
Wyróżnik: Δ = b² − 4ac Miejsca zerowe: x = (−b ± √Δ) / 2a
Postać wierzchołkowa
$$y = a(x-p)^2 + q$$
Wierzchołek: p = −b/2a, q = −Δ/4a Oś symetrii: x = p
Interpretacja Δ
Δ > 0 → dwa pierwiastki rzeczywiste Δ = 0 → jeden pierwiastek (podwójny) Δ < 0 → brak pierwiastków rzeczywistych
Jeśli a > 0: parabola otwarta w górę, minimum w wierzchołku. Jeśli a < 0: otwarta w dół, maksimum w wierzchołku.

Logarytmy i Wykładnicze

Definicja i Własności
$$\log_a b = c \iff a^c = b \qquad (a>0,\ a\neq 1,\ b>0)$$ $$\log_a(x \cdot y) = \log_a x + \log_a y$$ $$\log_a \frac{x}{y} = \log_a x - \log_a y$$ $$\log_a x^n = n \cdot \log_a x$$ $$\log_a b = \frac{\log_c b}{\log_c a} \quad \text{(zmiana podstawy)}$$
log₂(32) = 5, bo 2⁵ = 32  |  log₁₀(1000) = 3  |  ln(e³) = 3
Równania Wykładnicze i Logarytmiczne
Metoda: jeśli baza jednakowa → porównaj wykładniki. Jeśli różna → logarytmuj obie strony.
$$2^{x+1} = 8 \Rightarrow 2^{x+1} = 2^3 \Rightarrow x+1=3 \Rightarrow x=2$$
$$\log_2(x-1) = 3 \Rightarrow x-1 = 2^3 = 8 \Rightarrow x = 9$$
Zawsze sprawdź dziedzinę! Argument logarytmu musi być > 0.

Trygonometria

Trygonometria opisuje relacje między kątami a bokami — podstawa grafiki 3D, przetwarzania sygnałów (transformata Fouriera), nawigacji i elektrotechniki.
$$\sin^2\alpha + \cos^2\alpha = 1$$ $$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$$ $$\sin(A+B) = \sin A \cos B + \cos A \sin B$$ $$\cos(2\alpha) = \cos^2\alpha - \sin^2\alpha$$
Mnemonik ćwiartek: CAST — Cosinus (IV), Wszystkie (I), Sinus (II), Tangens (III).

Ciągi Liczbowe

Ciąg Arytmetyczny
Każdy wyraz różni się od poprzedniego o stałą różnicę r.
$$a_n = a_1 + (n-1)r \qquad S_n = \frac{(a_1+a_n) \cdot n}{2}$$
2, 5, 8, 11, 14... (r=3). Suma 100 wyrazów: S₁₀₀ = (2+299)·50 = 15050
Ciąg Geometryczny
Każdy wyraz to poprzedni pomnożony przez stały iloraz q (q ≠ 0, q ≠ 1).
$$a_n = a_1 \cdot q^{n-1} \qquad S_n = a_1 \cdot \frac{q^n - 1}{q-1}$$
$$S_\infty = \frac{a_1}{1-q} \quad \text{dla } |q| < 1$$
3, 6, 12, 24... (q=2)  |  1, ½, ¼, ⅛... (q=½) → S∞ = 1/(1-½) = 2

Geometria

Figury płaskie
Trójkąt: P = ½·a·h Równoboczny: P = (a²√3)/4 Koło: P = πr² | C = 2πr Trapez: P = ½·(a+b)·h Romb: P = ½·d₁·d₂ Równoległobok: P = a·h
Bryły przestrzenne
Sześcian: V = a³ | Pc = 6a² Prostopadł: V = a·b·c | Pc = 2(ab+bc+ac) Walec: V = πr²h | Pb = 2πrh Stożek: V = ⅓πr²h | l = √(r²+h²) Kula: V = ⁴⁄₃πr³ | Pc = 4πr²
Twierdzenia i wzory
Pitagoras: a²+b² = c² Twierdzenie Talesa: odcinki proporcjonalne Wzór Herona: P = √(s(s-a)(s-b)(s-c)) Obwód okręgu opisanego: R = abc/(4P) Obwód okręgu wpisanego: r = P/s
Przelicznik objętości: 1 m³ = 1000 dm³ = 1 000 000 cm³. Każde przejście między jednostkami to skok ×1000, nie ×10!

Kombinatoryka i Prawdopodobieństwo

Zliczanie
$$P_n = n! \quad \text{(permutacje n elementów)}$$ $$V_n^k = \frac{n!}{(n-k)!} \quad \text{(wariacje bez pow.)}$$ $$\binom{n}{k} = \frac{n!}{k!(n-k)!} \quad \text{(kombinacje)}$$
Ile słów z liter ABCD? P₄ = 24. Ile 2-elementowych podzbiorów z 5? C(5,2) = 10.
Prawdopodobieństwo Klasyczne
$$P(A) = \frac{|A|}{|\Omega|} \qquad P(\bar{A}) = 1 - P(A)$$ $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$ $$P(A|B) = \frac{P(A \cap B)}{P(B)} \quad \text{(warunkowe)}$$
Rzut kostką. P(parzysta) = 3/6 = ½. P(parzysta LUB >4) = 4/6 = ⅔.

Wstęp do Rachunku Różniczkowego

Pochodne — Reguły
$$(x^n)' = n x^{n-1} \qquad (e^x)' = e^x$$ $$(\ln x)' = \frac{1}{x} \qquad (\sin x)' = \cos x$$ $$(\cos x)' = -\sin x \qquad (\tan x)' = \frac{1}{\cos^2 x}$$ $$(f \cdot g)' = f'g + fg' \quad \left(\frac{f}{g}\right)' = \frac{f'g-fg'}{g^2}$$
f(x) = 3x⁴ − 2x² + 5 → f'(x) = 12x³ − 4x
Zastosowania Pochodnej
Monotoniczność: f'(x) > 0 → rosnąca. f'(x) < 0 → malejąca.
Ekstrema: f'(x₀) = 0 i zmiana znaku → extremum. Drugie kryterium: f''(x₀) > 0 → minimum, f''(x₀) < 0 → maksimum.
$$f(x) = x^3 - 3x \Rightarrow f'(x) = 3x^2-3 = 0 \Rightarrow x = \pm 1$$
x=−1: maksimum lokalne (f(−1) = 2). x=1: minimum lokalne (f(1) = −2).
