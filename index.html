Kroniki Matematyki 4 epoki

Starożytność (3000 p.n.e. – 500 n.e.)
Matematyka powstała z potrzeby — Egipcjanie mierzyli Nil i budowali piramidy, Babilończycy stworzyli system sześćdziesiątkowy. Grecy (Pitagoras, Euklides, Archimedes) wprowadzili dowód matematyczny — wiedza przestała być empiryczna.
Twierdzenie Pitagorasa: a² + b² = c² — dowiedzione przez Euklidesa na 46 różnych sposobów.
Złoty Wiek Islamu & Indie (500–1400)
Indie podarowały światu zero i system pozycyjny. Al-Chuwarizmi napisał pierwsze systematyczne omówienie algebry. Bez tego Europa nie miałaby podstaw do Rewolucji Naukowej.
Al-jabr → Algebra. Al-Chuwarizmi → Algorithm. Cyfra arabska 0 → cały system pozycyjny.
Rewolucja Naukowa (1500–1800)
Newton i Leibniz niezależnie wynaleźli rachunek różniczkowy. Euler sformalizował notację: \(e, \pi, i, f(x), \sum\). Wielkie Twierdzenie Fermata czekało na dowód 358 lat.
e^(iπ) + 1 = 0 — tożsamość Eulera: 5 najważniejszych stałych w jednym równaniu.
Era Komputerów (1900–teraz)
Gödel udowodnił (1931), że każdy spójny system zawiera twierdzenia nierozstrzygalne. Turing stworzył matematyczne podstawy komputerów.
Problem P vs NP — jeden z 7 Problemów Milenijnych. Nagroda: 1 000 000 USD. Nierozwiązany.

Anomalie Wszechświata 6 faktów

0.999... = 1 (dokładnie)
Dowód: \(\frac{1}{3} = 0.333...\), więc \(3 \times \frac{1}{3} = 0.999...\), ale \(\frac{3}{3} = 1\). Formalnie: \(0.\overline{9} = \sum_{n=1}^{\infty} \frac{9}{10^n} = 1\).
Hotel Hilberta
Hotel z nieskończenie wieloma pokojami, wszystkie zajęte. Przyjeżdża nowy gość — przenosimy gościa z pokoju n do n+1. ∞ + 1 = ∞.
Liczba Googolplex
Googolplex = \(10^{10^{100}}\). Zapis dziesiętny nie zmieściłby się w obserwowalnym wszechświecie.
Złota Proporcja φ
Ciąg Fibonacciego: 1,1,2,3,5,8... \(\frac{F_{n+1}}{F_n} \to \varphi = \frac{1+\sqrt{5}}{2} \approx 1.618\). Pojawia się w spirali ślimaka i partyturach Debussy\'ego.
Teoria Chaosu
Układ deterministyczny może być nieprzewidywalny. Efekt motyla Lorenza: trzy proste równania, nieskończona złożoność.
Paradoks Urodzin
W grupie zaledwie 23 osób prawdopodobieństwo wspólnych urodzin > 50%. Przy 70 osobach — 99.9%.

Fundamentalne Stałe

Liczby niewymierne i przestępne — ich rozwinięcie dziesiętne jest nieskończone i nieokresowe.
π ≈ 3.14159265358979... — stosunek obwodu koła do średnicy e ≈ 2.71828182845904... — podstawa logarytmu naturalnego
φ = (1+√5)/2 ≈ 1.61803398... — złota proporcja i = √(-1) — jednostka urojona, baza liczb zespolonych
Tożsamość Eulera: e^(iπ) + 1 = 0 — łączy wszystkie 5 stałych w jednym równaniu.

Algebra

Wzory Skróconego Mnożenia
$$(a \pm b)^2 = a^2 \pm 2ab + b^2$$ $$a^2 - b^2 = (a-b)(a+b)$$ $$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$$
Przykład: (2x+3)² = 4x² + 12x + 9
Najczęstszy błąd: pominięcie środkowego wyrazu 2ab w kwadracie sumy.
Potęgi i Pierwiastki
$$a^m \cdot a^n = a^{m+n} \qquad (a^m)^n = a^{m \cdot n}$$ $$a^0 = 1 \quad a^{-n} = \frac{1}{a^n} \quad a^{\frac{m}{n}} = \sqrt[n]{a^m}$$
2³ · 2⁵ = 2⁸ = 256 | 27^(2/3) = (∛27)² = 9
Równania Kwadratowe
$$ax^2 + bx + c = 0 \quad \Delta = b^2 - 4ac$$ $$x = \frac{-b \pm \sqrt{\Delta}}{2a}$$
Δ > 0: dwa pierwiastki | Δ = 0: jeden | Δ < 0: brak rzeczywistych

Funkcja Kwadratowa

Funkcja \(f(x) = ax^2 + bx + c\) opisuje parabolę — trajektorię rzutu ukośnego i kształt luster teleskopów.
Postać ogólna
$$y = ax^2 + bx + c$$
Wyróżnik: Δ = b² − 4ac
Postać wierzchołkowa
$$y = a(x-p)^2 + q$$
Wierzchołek: p = −b/2a, q = −Δ/4a

Logarytmy i Wykładnicze

Własności Logarytmów
$$\log_a(x \cdot y) = \log_a x + \log_a y$$ $$\log_a x^n = n \cdot \log_a x$$ $$\log_a b = \frac{\log_c b}{\log_c a}$$
log₂(32) = 5, bo 2⁵ = 32 | ln(e³) = 3
Równania Wykładnicze
$$2^{x+1} = 8 \Rightarrow 2^{x+1} = 2^3 \Rightarrow x=2$$ $$\log_2(x-1) = 3 \Rightarrow x = 9$$
Zawsze sprawdź dziedzinę! Argument logarytmu > 0.

Trygonometria

$$\sin^2\alpha + \cos^2\alpha = 1$$ $$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$$ $$\sin(A+B) = \sin A \cos B + \cos A \sin B$$
Mnemonik ćwiartek: CAST — Cosinus (IV), Wszystkie (I), Sinus (II), Tangens (III).

Ciągi Liczbowe

Ciąg Arytmetyczny
$$a_n = a_1 + (n-1)r \qquad S_n = \frac{(a_1+a_n) \cdot n}{2}$$
2, 5, 8, 11, 14... (r=3). Suma 100 wyrazów: S₁₀₀ = 15050
Ciąg Geometryczny
$$a_n = a_1 \cdot q^{n-1} \qquad S_\infty = \frac{a_1}{1-q} \quad (|q| < 1)$$
1, ½, ¼, ⅛... → S∞ = 1/(1-½) = 2

Wstęp do Rachunku Różniczkowego

Pochodne — Reguły
$$(x^n)\' = n x^{n-1} \qquad (e^x)\' = e^x$$ $$(\ln x)\' = \frac{1}{x} \qquad (\sin x)\' = \cos x$$ $$(f \cdot g)\' = f\'g + fg\'$$
f(x) = 3x⁴ − 2x² + 5 → f\'(x) = 12x³ − 4x
Zastosowania Pochodnej
Monotoniczność: f\'(x) > 0 → rosnąca. f\'(x) < 0 → malejąca.
Ekstrema: f\'(x₀) = 0 i zmiana znaku → extremum.
$$f(x) = x^3 - 3x \Rightarrow f\'(x) = 3x^2-3 = 0 \Rightarrow x = \pm 1$$
